# 在席管理ボード (Presence Manager)

研究室メンバーの在席状況をリアルタイムで管理するWebアプリケーション。

## 概要

研究室のメンバーが「在室」「帰宅」「外出」などの在席状況をワンタップで更新・共有できるボードアプリ。スマートフォン・PCどちらからでも操作できるレスポンシブ対応。

## 機能

- メンバーの在席ステータスをワンタップで更新
- 今週の在室時間の自動集計・表示
- 管理者画面からメンバー・ステータスの追加・削除
- ドラッグ＆ドロップによるメンバーの並び替え
- 操作ログの記録・閲覧
- 夜間・昼間で自動更新頻度を切り替えるスマートポーリング

## 技術スタック

### フロントエンド
- TypeScript
- Vite（ビルドツール）

### バックエンド
- Python / FastAPI
- PostgreSQL（Neon）

### インフラ
- Vercel（ホスティング・サーバーレス関数）

## 開発の背景

研究室の在席状況を共有する手段がなく、メンバーが互いの状況を把握しにくいという問題を解決するために開発。当初はJavaScriptで実装し、型安全性と保守性向上のためTypeScript + Viteに移行。

## ローカル開発

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build
```
